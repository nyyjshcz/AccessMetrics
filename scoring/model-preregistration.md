# accesscheck-score-v1 模型预注册

本文件在正式研究扫描前冻结，不写入尚未产生的正式分数或排名。

## 预先锁定

- 自动化检查机会使用 axe 的 pass/fail 节点作为分母；`incomplete` 和 `inapplicable` 不直接扣分。
- 严重度权重为 critical/serious/moderate/minor = 4/3/2/1，内部按 40/30/20/10 的整数精确保存。
- 总分按全部页面、全部规则节点汇总，不对页面分数做简单平均。
- 四项原则分别按 WCAG 映射计算，无法建立检查机会时显示 N/A。
- 最终展示只做一次 round-half-up 到一位小数；排名使用未舍入精确分数。

## 备选与理由

研究中另外运行 5/3/2/1 与 4/2.5/1.5/1 两个敏感性方案。主模型选择 4/3/2/1 是为了让严重度有清晰、可解释、可复核的单调差异，同时避免页面 DOM 数量被人为放大。正式数据完成后另写模型观察记录，不回写本文件。
