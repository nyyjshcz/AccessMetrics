# 历史归档

本目录只保存旧方案、旧验证记录和早期交付物，便于追溯；它们不用于说明当前运行中的 AccessCheck。第一次了解项目时不要从这里开始，请从[文档地图](../README.md)开始。

`legacy/` 按材料用途分为四类：

- `plans/`：旧实施方案、门禁和 AI 方案审计。
- `handoff/`：旧版角色交接、练习、问答和理解检查材料。
- `validation/`：旧依赖快照、文档检查和版本验证记录。
- `research/`：早期站点调研和人工审核记录。

这些文件可能出现已经废弃的权限角色、R1–R5、formal study、旧命令或旧页面路径。它们只用于了解项目演进，不能当作当前功能或操作指南。
