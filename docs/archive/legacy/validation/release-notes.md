# 版本说明快照（历史参考）

> 本文是一次版本说明快照。当前项目范围请看[项目说明](../../../项目说明.md)，当前启动和验证方式请看根目录 README。

## 当前产品范围

AccessCheck Lishui 是一个可自托管的网页无障碍评估工具，当前版本提供：

- 管理员与报告访客两类访问密钥；
- 公开网站的同站页面发现、Playwright 渲染与 axe-core 扫描；
- 页面、规则、节点级证据与四项原则评分；
- 原始分数与人工/AI 复核后的有效分数；
- 可暂停、恢复、自动重试的 run-wide AI incomplete 复核；
- 已发布后只读的 HTML、PDF、JSON 报告；
- 未发布终态任务的安全删除；
- 本地三进程启动与单 VPS compose 部署材料。

## 当前展示原则

1. 报告先呈现结论、覆盖范围和高优先级事项，详细节点证据按需展开。
2. 页面上限、扫描失败和 incomplete 结果必须明确呈现，不能通过模糊统计掩盖。
3. AI 是补充复核，不会覆盖原始 axe 结果；人工结论优先于 AI。
4. 发布后内容只读，报告访客不能查看未发布数据或管理界面。

## 当前验证入口

开发完成后使用 pnpm test:all。该命令依次运行 lint、typecheck、Vitest、生产构建和 Playwright 浏览器流程。部署文件还应额外运行 pnpm ops:check 和 pnpm deploy:check。

## 已知边界

- 评分是自动化筛查和比较工具，不能等同于完整人工审计或 WCAG 官方合规认证。
- 本地 SQLite 目标规模是小型演示和有限站点集合；不是高并发多租户平台。
- 生产部署仍需要真实的域名、TLS、Linux 主机、私有 secret、固定 egress proxy 镜像和网络运维输入。
