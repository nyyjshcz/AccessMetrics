# AccessCheck 文档地图

> **谁需要读：所有人。是否必读：是。** 先看本页，再按角色只读一条路径。不要把整个 `docs/` 目录当成必读清单。

这个目录曾积累过多轮方案、验证记录和交接材料。它们没有被删除，但**不应默认被当作当前项目说明**。如果你是第一次了解项目，请只按下面的“当前资料”阅读。

## 所有人先读

| 必读资料 | 读完要知道什么 |
| --- | --- |
| [项目说明](./项目说明.md) | 项目做什么、一次扫描怎么走、报告能说明什么，以及不能怎样宣传。 |

## 按角色阅读

所有人都先读[项目说明](./项目说明.md)。读完后只按自己的角色看下面一行，不需要把所有列出的资料读一遍。

| 角色 | 必读 | 选读 | 不用读 |
| --- | --- | --- | --- |
| 数学负责人 | [项目说明](./项目说明.md)、[数学负责人完整理解指南](./数学负责人完整理解指南.md) | [评分解释](./scoring-explained.md)、[数据字典](./data-dictionary.md)、`src/lib/score.ts`、`src/lib/run-score.ts` | 架构、运维、部署、历史归档 |
| 教授、项目评审、展示者 | [项目说明](./项目说明.md)、[评分解释](./scoring-explained.md)、[标准映射](./standards-crosswalk.md) | 已发布报告中的问题和节点证据 | 代码、运维、部署、数学负责人完整指南、历史归档 |
| 代码负责人 | 根目录 [README](../README.md)、[项目说明](./项目说明.md)、[架构](./architecture.md) | [数据字典](./data-dictionary.md)、[安全边界](./安全边界.md) | 数学负责人完整指南、历史归档；生产部署、代理、密钥、备份或运行故障时转读[运维说明](./operations.md)和[部署说明](./ops/deployment.md) |
| 部署负责人 | 根目录 [README](../README.md)、[项目说明](./项目说明.md)、[运维说明](./operations.md)、[部署说明](./ops/deployment.md)、[安全边界](./安全边界.md) | [架构](./architecture.md)、[数据字典](./data-dictionary.md) | 数学负责人完整指南、评分解释、历史归档 |
| 报告访客 | 无内部文档 | 已发布报告 | `docs/` 内部资料全部不用读 |

## 按需查阅的参考资料

除上表已列为角色必读的资料外，这些文件不是任何角色的第一轮必读资料。部署负责人仍须按上表阅读[安全边界](./安全边界.md)、[运维说明](./operations.md)和[部署说明](./ops/deployment.md)；其他角色遇到具体问题时再打开即可。

| 资料 | 用途 |
| --- | --- |
| [数据字典](./data-dictionary.md) | 查数据库字段、结果计数和数据之间的关系。 |
| [标准映射](./standards-crosswalk.md) | 查 axe 规则、WCAG 标签和评分之间的边界。 |
| [安全边界](./安全边界.md) | 查密钥、访问限制、扫描目标和发布限制。 |
| [运维说明](./operations.md)、[部署说明](./ops/deployment.md) | 遇到运行/部署问题时，查启动、排障、代理、密钥、备份和生产部署步骤。 |

## 阅读边界

本目录只保留当前操作和理解项目所需的资料。未列在角色路径中的文件只在有具体问题时查阅；描述当前功能时，以本页列出的资料和代码为准。
