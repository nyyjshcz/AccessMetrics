# 标准映射与解释边界

> **谁需要读：教授、项目评审和展示者。是否必读：是。** 这是评审阅读路径的必读资料。其他角色只在需要核对规则来源时查阅。读完你会知道规则怎样映射到 WCAG A/AA，以及映射不能证明什么。

## 当前映射做什么

扫描使用 axe-core 的规则结果，并以项目维护的[冻结规则目录](../configs/axe-rule-catalog.json)将规则映射到 WCAG 2.2 成功准则和四项原则：可感知（Perceivable）、可操作（Operable）、易理解（Understandable）、兼容性（Robust）。当前规则目录版本为 `wcag-2.2-axe-4.13.0-v1`。该目录是项目维护的规则映射数据，不是 WCAG 官方认证清单。当前工作只做 WCAG 2.2 映射，不等于中国国家标准、地方标准或其他法规的符合性评估。

映射的来源与步骤如下：

1. axe 运行时返回规则 ID、标签、影响等级和节点证据；这些是原始扫描证据。
2. [冻结规则目录](../configs/axe-rule-catalog.json)给出已知规则的 WCAG 准则、原则、等级和是否计分。它是项目维护的数据，不是 WCAG 官方认证清单。
3. 对目录外的规则，系统只从符合 `wcagNNN` 格式的 axe 标签中解析候选准则；若当前 WCAG 目录无法核对，则不把它纳入评分。
4. 只有映射到 WCAG A 或 AA 的规则才具有 `scoring_eligible=true`。AAA-only、best-practice、未知或未映射规则仍会在扫描结果中显示，但不会悄悄影响分数。

## 报告中的标签应怎样理解

| 标签 | 含义 | 不代表什么 |
| --- | --- | --- |
| WCAG 准则 | 自动规则被映射到的成功准则编号。 | 不是人工确认该网页满足或违反该准则的完整结论。 |
| A / AA / AAA | 规则目录中的 WCAG 等级。 | 不是网站整体的 A、AA 或 AAA 认证。 |
| best-practice | axe 的最佳实践规则。 | 不会进入当前评分模型。 |
| 未映射 WCAG | 扫描标签无法由当前冻结目录可靠核对。 | 不应根据记忆补写标准条款或强行计分。 |
| incomplete | 自动化规则无法可靠下结论。 | 不是通过，也不是自动失败；须保留为待进一步判断。 |

## 与评分的关系

规则映射负责确定一条规则属于哪些原则、是否具备 A/AA 计分资格；评分模型再根据节点的 `critical`、`serious`、`moderate`、`minor` 权重计算结果。两者分工不同：

- 映射回答“这条规则在哪个 WCAG / 原则语境中”；
- 评分回答“在本次自动筛查模型中，已判定节点造成多大扣分”；
- `incomplete` 单独呈现覆盖与复核情况，原始状态不扣分。

详见 [评分解释](./scoring-explained.md)。

## 明确不做的事

- 不把 axe 结果宣传为完整人工无障碍审计；
- 不把 0 到 100 分宣传为 WCAG 合规百分比；
- 不凭记忆生成中国国家标准、地方标准或其他法规的具体条文对照；
- 不让未知规则、AAA-only 或最佳实践规则在没有明示的情况下改变总分。

需要逐项核对某条规则时，应回到报告中的 rule ID、axe help 链接、扫描时保存的标签和 `configs/axe-rule-catalog.json`，而不是只依据页面上简化后的中文说明。
