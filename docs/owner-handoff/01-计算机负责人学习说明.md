# 计算机负责人学习说明

## 学习顺序

1. `src/lib/url-security.ts`：输入 URL、DNS、重定向和子资源都走同一 DestinationPolicy；私网地址、凭据、metadata 和非 HTTP(S) 会被拒绝。
2. `src/lib/crawler.ts` 与 `src/lib/scan-page.ts`：crawler 只发现同站 HTML，scanner 运行 axe 四组结果并记录 frame 覆盖。
3. `src/lib/db.ts` 与 `src/worker/index.ts`：SQLite migration、WAL、job/page lease、heartbeat、取消和崩溃恢复共同保证不重复扫描。
4. API：服务端从 Cookie 派生 role，CSRF 与 Origin 同时校验；admin、computer reviewer、math reviewer 三种权限不能互换。
5. `src/lib/export.ts`、`src/lib/study-export.ts`：原始字节、manifest、source/final 状态和 publication CAS 让结果可追溯。
6. `scripts/gates-index.ts`、`scripts/gates-seal.ts`：只接受 schema-valid、hash 匹配的真人 receipt，不接受目录里随便放文件。
