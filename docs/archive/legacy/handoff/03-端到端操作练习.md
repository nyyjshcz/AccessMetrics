## 操作步骤（空表）

1. 依赖和格式：`pnpm dependency:preflight`、`pnpm lint`、`pnpm format:check`。
2. 数据库：`pnpm db:migrate`、`pnpm db:check`，记录 migration 版本和外键状态。
3. fixture：只在测试 DestinationPolicy 放行的随机端口运行 fixture；生产不可把 localhost 放行。
4. 管理登录 → 新建扫描 → Worker 完成 → 结果页 → 问题筛选 → HTML/PDF/JSON/CSV 导出。
5. reviewer 登录：双方分别取固定 sample，提交 verdict；分歧由另一角色批准裁决；冻结 review set。
6. 复核 manifest、隐私报告和 publication gate；未满足 release_ready 时尝试公开应得到拒绝。
7. 用外部 key 执行加密备份/恢复，在新目录运行 `db:check` 和 `gates:verify`。
