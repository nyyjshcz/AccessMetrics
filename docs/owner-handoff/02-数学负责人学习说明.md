# 数学负责人学习说明

## 学习顺序

1. 原始机会来自 violation 节点；incomplete 单独披露但不进入确定性评分分母。
2. violation 节点优先使用 node impact，其次 rule impact，二者为空才回退固定权重；来源必须保存。
3. 总分使用整数分子/分母汇总，最后才 half-up 到一位小数；不能平均已舍入页面分。
4. 四项分按 WCAG 原则映射，多原则规则在总分只计一次，在原则分可分别显示贡献。
5. 人工复核只用于样本内一致性、分歧和裁决描述，不可写成总体准确率或假阳性率。
6. 敏感性分析固定三套权重，排名使用未舍入精确值，tie 按稳定规则处理。
